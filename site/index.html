Plex Discord Presence

Show what you watch and listen to on Plex as Discord Rich Presence. One file, no npm packages, LAN-only, no tracking.

Install

curl -fsSL https://INSTALLER_HOST/install.sh | sh
irm https://INSTALLER_HOST/install.ps1 | iex

Brings its own Node.js if you have none (official nodejs.org build, SHA-256 checked). No sudo or admin rights. Needs the Discord desktop app and a Plex server on your network. Read the installer first if you like.
